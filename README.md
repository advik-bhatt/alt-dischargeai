# DischargeAI
Rutgers Health Hack 2026

Backend (branch `backend`, code under `backend/`): discharge summaries in, a plain-language patient link out, data self-destructs after 30 days. Node 24. Run it with `cd backend && npm install && npm run dev`; everything else, including the demo, the team infrastructure and what the other branches add, is in [backend/README.md](backend/README.md).
